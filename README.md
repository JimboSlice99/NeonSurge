# NEON SURGE

**Tower defense** for Roblox — Rojo + Luau only.

Defend the **Surge Core**. Place neon towers on plots along the conduit path. Survive 25 waves.

## How to play

1. **START DEFENSE**
2. Press **1–4** to choose a tower (Pulse / Beam / Frost / Nova)
3. **Left-click** a plot to place (or upgrade if occupied)
4. **Right-click** a tower plot to sell (60% refund)
5. Stop leaks — each enemy that reaches the core costs lives

## Progression

- Earn **credits** from waves cleared
- Buy permanent ops: starting cash, tower damage/range, core lives
- Gamepass hooks ready in `Config.luau`

## Run

```powershell
aftman install
rojo build -o NeonSurge.rbxlx
```

Open in Studio → Play.
