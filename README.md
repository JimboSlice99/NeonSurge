# SURGE

Industrial **tower defense** for Roblox (Rojo + Luau).

Defend the core. Place turrets on the path. Survive 25 waves.

Matte concrete/steel look — no neon materials.

## Controls

| Input | Action |
|-------|--------|
| 1–4 | Select tower |
| LMB plot | Place / upgrade |
| RMB plot | Sell |
| R | Lobby |

## Run

```powershell
aftman install
rojo build -o NeonSurge.rbxlx
```

Open in Studio → Play → **START DEFENSE**.
